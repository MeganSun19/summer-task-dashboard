# 人工录音替换说明

人工录音不是必做项。只有 TTS 单词在试听时出现发音、尾音或自然度问题，才需要替换。

1. 在安静房间用手机或电脑录制，正常自然地读一次完整单词，不要读字母名。
2. 文件以单词命名，例如 `ship.m4a`、`frog.wav` 或 `hand.mp3`。
3. 放入 `human-recordings/phonics-words/`。
4. 重新运行 `node scripts/generate-phonics-word-audio.mjs`。

生成脚本会优先使用同名单词的人工录音，并统一为单声道 MP3、标准音量和前后留白。旧的 TTS 候选会被替换，但仍需在试听页重新审核。

逐音示范（如 `/sh/ /i/ /p/ → ship`）后续单独录制，不要混入单词听辨文件；当前孩子端听辨题只播放完整单词。
